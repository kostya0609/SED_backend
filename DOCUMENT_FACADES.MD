## Фасады для работы с документами

### SEDDirectiveFacade

#### Пример использования

```php
use SED\Facades\SEDDirectiveFacade;

/** Получаем поручение по его идентификатору */
$directive = SEDDirectiveFacade::findById(1);

/** Если поручение на подготовке, то получаем контроллеров */
if ($directive->isPreparation()) {
	$controllers = SEDDirectiveFacade::getControllers($directive->id);
}
```

Таблица с методами фасада поручения:

| Метод                                                    | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `findById(int $document_id): Directive`                     | Находит поручение по идентификатору. Возвращает модель поручения или выбрасывает исключение `NotFoundException`, если поручение не найдено.                                                                                                                                                                                                                                                                                                                           |
| `update(UpdateDirectiveDto $dto): Directive`                | Обновляет существующее поручение на основе данных из DTO. Метод доступен только для поручений в статусе "На подготовке" или "Черновик". Обновляет основные данные поручения, участников и связанные записи. Возвращает обновленное поручение.                                                                                                                              |
| `getExecutors(int $document_id): Collection`                | Возвращает коллекцию идентификаторов пользователей, являющихся исполнителями указанного поручения.                                                                                                                                                                                                                                                                                                                                                                                    |
| `getControllers(int $document_id): Collection`              | Возвращает коллекцию идентификаторов пользователей, являющихся контролерами указанного поручения.                                                                                                                                                                                                                                                                                                                                                                                      |
| `cancel(int $document_id): Directive`                       | Отменяет поручение, находящееся в статусе "Подготовка". Выполняет переход поручения в статус "Отменено". Возвращает обновленное поручение или выбрасывает исключение, если поручение не может быть отменено.                                                                                                                                                                                       |
| `getDocumentParticipants(int $document_id): array`          | Возвращает массив идентификаторов всех участников указанного поручения.                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `sendToApproval(int $document_id, int $user_id): Directive` | Отправляет поручение на согласование. Проверяет наличие автора и исполнителей, создает или перестраивает процесс согласования и запускает его с указанием пользователя, который запускает процесс. Возвращает обновленное поручение или выбрасывает исключение при невозможности отправки на согласование. |

#### Модель поручения

Основные атрибуты:

| Атрибут             | Тип   | Описание                                                                             |
| -------------------------- | -------- | -------------------------------------------------------------------------------------------- |
| `id`                     | int      | Уникальный идентификатор поручения                           |
| `number`                 | string   | Номер поручения                                                                |
| `type_id`                | int      | Идентификатор типа документа                                       |
| `status_id`              | int      | Идентификатор статуса поручения                                 |
| `executed_at`            | datetime | Срок исполнения поручения                                             |
| `process_template_id`    | int      | Идентификатор шаблона процесса                                   |
| `department_id`          | int      | Идентификатор подразделения                                        |
| `execution_control_date` | datetime | Дата контроля исполнения                                               |
| `theme_title`            | string   | Заголовок темы поручения                                               |
| `tmp_doc_id`             | int      | Идентификатор шаблона документа (опционально)        |
| `document_hierarchy_id`  | int      | Идентификатор в иерархии документов (опционально) |
| `common_document_id`     | int      | Идентификатор общего документа (опционально)          |

Вычисляемые атрибуты:

| Атрибут          | Тип   | Описание                                                                 |
| ----------------------- | -------- | -------------------------------------------------------------------------------- |
| `theme`               | string   | Тема поручения (из шаблона или из заголовка) |
| `parent_document`     | Document | Родительский документ в иерархии                    |
| `documents_hierarchy` | mixed    | Иерархия документов из фасада DocumentsHierarchy       |

Методы проверки статуса:

| Метод                     | Возвращаемый тип | Описание                                                                                                                             |
| ------------------------------ | ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `isPreparation()`            | bool                            | Проверяет, находится ли поручение в статусе "На подготовке"                                 |
| `isExecutionChangeRequest()` | bool                            | Проверяет, находится ли поручение в статусе "Запрос на изменение исполнения" |
| `isExecutionInWork()`        | bool                            | Проверяет, находится ли поручение в статусе "В работе"                                           |
| `isExecutionControl()`       | bool                            | Проверяет, находится ли поручение в статусе "На контроле"                                     |
| `isArchiveWorked()`          | bool                            | Проверяет, находится ли поручение в статусе "В архиве (отработано)"                    |
| `isArchiveCancelled()`       | bool                            | Проверяет, находится ли поручение в статусе "В архиве (отменено)"                        |
| `isDraft()`                  | bool                            | Проверяет, находится ли поручение в статусе "Черновик"                                          |

### SEDESZFacade

#### Пример использования

```php
use SED\Facades\SEDESZFacade;

/** Получаем ЭСЗ */
$esz = SEDESZFacade::findById(1);

/** Проверяем, что ЭСЗ находится в статусе Устранение замечаний полсе резолюции */
if ($esz->isFixResolution()) {
	/** Логика обработки ЭСЗ */
}
```

Таблица с методами фасада ЭСЗ:

| Метод                                 | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `findById(int $document_id): Esz`        | Находит ЭСЗ (электронную служебную записку) по идентификатору. Возвращает модель ЭСЗ или выбрасывает исключение `NotFoundException`, если ЭСЗ не найдена.                                                                                                                                                                                                                                                                                                                     |
| `update(UpdateESZDto $dto): Esz`         | Обновляет существующую ЭСЗ на основе данных из DTO. Метод доступен только для ЭСЗ в статусах "Черновик", "На подготовке", "На устранении замечаний", "На устранении замечаний (подписание)" или "На устранении замечаний (резолюция)". Обновляет основные данные ЭСЗ, участников и связанные записи. Возвращает обновленную ЭСЗ. |
| `sendToApproval(int $document_id): Esz`  | Отправляет ЭСЗ на согласование. Если ЭСЗ находится в статусе "На устранении замечаний (подписание)" или "На устранении замечаний (резолюция)", перестраивает процесс согласования. Возвращает обновленную ЭСЗ.                                                                                                                                                                                                       |
| `cancellation(int $document_id): Esz`    | Аннулирует ЭСЗ. В зависимости от текущего статуса ЭСЗ выполняет соответствующий переход в статус "В архиве (отменено)". Удаляет активный процесс, если он существует. Возвращает обновленную ЭСЗ.                                                                                                                                                                                                                               |
| `sendToSignatory(int $document_id): Esz` | Отправляет ЭСЗ на подписание. Метод доступен только для ЭСЗ в статусе "На подготовке". Удаляет текущий процесс согласования, меняет шаблон процесса на процесс подписания и создает новый процесс. Возвращает обновленную ЭСЗ.                                                                                                                                                                        |

### SEDReviewFacade

#### Пример использования

```php
use SED\Facades\SEDReviewFacade;

/** Получаем ознакомление */
$review = SEDReviewFacade::findById(1);

/** Если ознакомление на статусе Черновик, то получаем участников ознакомления для дальнейшей обработки */
if ($review->isDraft()) {
	$receivers = SEDReviewFacade::getReceivers($review->id);
}
```

| `findById(int $document_id): Review`         | Находит документ ознакомления по идентификатору. Возвращает модель ознакомления или выбрасывает исключение `NotFoundException`, если документ не найден.                                                                                                                                                                                                                     |

Обновляет основные данные документа, участников и связанные записи. Возвращает обновленный документ ознакомления. |
